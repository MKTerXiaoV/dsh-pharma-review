# 五关总体检

单项体检看一块砖，总体检看这堵墙立不立得住：上游没核的数字，会被分析引用、被洞察当证据、被关键信息写成卖点、被活动搬上讲台。所以五关要按顺序过，还要看关和关之间接没接上。

## 流程

### 0. 合规前置
先按关键信息体检的合规红线扫一遍全文。命中整份拦停的（超适应症、绝对化疗效承诺、贬低竞品等），这份方案不往下审：只说拦停原因和改法，存档时触发的那一关记 `拦停`，其余关记 `未提交`。

### 1. 拆材料
指出五部分各在哪（页码或段落）。某一部分材料里没有，就记 `未提交`，不硬评、不替用户补写。拆分结果用一两行告诉用户，然后直接往下审，除非拆不清才问。

### 2. 逐关体检（按顺序）
| 顺序 | 关 | 用的 skill | 老板那句话 |
|---|---|---|---|
| 1 | 证据 | `evidence-review` | 这个数字哪来的？ |
| 2 | 分析 | `business-analysis-review` | 所以呢？下一步干什么？ |
| 3 | 洞察 | `insight-review` | 这句是洞察还是常识？ |
| 4 | 关键信息 | `key-message-review` | 医生记得住吗？ |
| 5 | 活动 | `activity-design-review` | 这场活动推动了啥？ |

每关加载对应 skill，按它的评分卡判。默认用速检档；用户说“深度”才用标准档；“上评审团”只在用户点名时用，且先报成本。

每关只留三样：**评级**（未及格线 / 及格 / 良好 / 优秀）、**最要命的至多 3 条刺**、**最该先做的 1 条改法**。其余细节用户追问再展开。

### 3. 查断链（总体检独有）
五关各自及格，方案仍可能是散的。逐条看下面五个接口，找出断了的，至多列 3 处，每处写清从哪关断到哪关：

1. **证据 → 分析**：分析里用的数字，有没有证据关判为 C 级（无源）或“待核”的？
2. **分析 → 洞察**：分析读出的机会（哪群人、哪个缺口），洞察有没有接住？还是洞察另起一个话题？
3. **洞察 → 关键信息**：关键信息回应的是不是这条洞察里的障碍？
4. **关键信息 → 活动**：活动的“主菜”是不是这条关键信息？医生走出会场记住的是它吗？
5. **活动 → 分析**：活动的覆盖对象，是不是分析里锁定的那群人？

### 4. 总评
- **短板定总评**：总评跟着最弱的一关走，不取平均。五关有一关未及格线，整份就是“建议返工”。
- **先改哪里**：上游优先。证据关有问题先改证据，因为下游都建在它上面；同级的先改断链。

### 5. 交付与存档
总体检单的格式：

```
《方案名》五关总体检

总评：一句话
先改：一句话

证据      评级   刺 1 / 刺 2 / 刺 3   → 改法
分析      …
洞察      …
关键信息  …
活动      …

断链：
- 洞察 → 关键信息：……
```

然后调用 `pharma_review_record` 存档：mode 填 `five`，gates 填五关（没有的记 `未提交`），chain 填断链，verdict 填总评，next 填先改哪里。告诉用户：改完把新版本贴过来说“复检”，会逐条对照上次的问题。

## 复检
用户说“复检”并给出改后版本时，按上次的问题对照（从档案页点“复检”会自动带上；没带的话请用户贴上次的问题）。逐条标 ✅ 改到位 / ⚠️ 改了一半 / ❌ 没改，再给新评级，用同一个方案名存档，档案会自动排成改前改后。

## 红线
- 只审不写：可以给改法和示范句，不替用户重写整份方案。
- 不编数据：用户材料里没有的数字，不补、不估。
- 评级给真话：五关全优秀很少见，不为了好看抬分。
